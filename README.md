# PC Benchmark

Програма визначення продуктивності ПК з використанням алгоритмів стрес-тестування.
Курсовий проєкт на Python: лише стандартна бібліотека, графічний інтерфейс на tkinter.

## Що тестується

| Підсистема | Алгоритми | Результат |
|---|---|---|
| Процесор, 1 ядро | Решето Ератосфена, множина Мандельброта, множення матриць, SHA-256, zlib, сортування | час, бали |
| Процесор, усі ядра | Композитне завдання в N процесах | завдань/с, прискорення, ефективність масштабування |
| Відеокарта | Шейдери OpenGL: FP32-обчислення, фрактал, заповнення, текстурні вибірки | GFLOPS, Мпікс/с, Гпікс/с, Гтекс/с |
| Оперативна пам'ять | Запис, читання, копіювання блоку 256 МБ | ГБ/с |
| Накопичувач | Послідовний запис/читання, випадкові 4K операції | МБ/с, IOPS |
| Стрес-тест | Тривале навантаження всіх ядер з перевіркою контрольних сум | помилки, тротлінг, стабільність |

Бали: 1000 = умовний еталонний ПК. Загальний бал — зважене середнє геометричне категорій.
Вкладка «Порівняння» показує ваш ПК серед еталонних систем, ваших попередніх запусків та імпортованих звітів з інших комп'ютерів.

## Встановлення

**[⬇ Завантажити PC-Benchmark-Setup.exe](https://github.com/zimbo812/pc-benchmark/releases/latest/download/PC-Benchmark-Setup.exe)** (остання версія) і запустити.
Усі версії — у розділі [Releases](https://github.com/zimbo812/pc-benchmark/releases).
Установник не потребує прав адміністратора, створює ярлики та за бажанням додає програму в автозапуск Windows.
Після запуску програма сама перевіряє, чи вийшла нова версія, і пропонує оновитися.

## Запуск з вихідного коду

Потрібен Python 3.8+ (Windows; на macOS/Linux працюють усі тести, крім GPU).

```
python benchmark_v0.10.py                    # графічний інтерфейс
python benchmark_v0.10.py --cli --stress 60  # консольний режим
python benchmark_v0.10.py --help             # усі параметри
```

## Збирання .exe та установника

Потрібні [PyInstaller](https://pyinstaller.org) (`pip install pyinstaller`) та [Inno Setup 6](https://jrsoftware.org/isdl.php).

```
powershell -ExecutionPolicy Bypass -File build.ps1 -Version 0.10
```

Результат: `build\installer\PC-Benchmark-Setup.exe`.

## Структура

- `benchmark_v0.X.py` — версії програми, кожна запускається самостійно (історія змін — у [CHANGELOG.md](CHANGELOG.md))
- `installer/pc_benchmark.iss` — сценарій установника Inno Setup
- `build.ps1` — збирання .exe та установника
- `tools/make_icon.py`, `assets/pcbench.ico` — іконка програми
