# PC Benchmark — історія версій

Кожна версія — окремий файл, який запускається самостійно:
`python benchmark_v0.X.py` (графічний інтерфейс) або `python benchmark_v0.X.py --cli` (консоль).

## 0.8 — `benchmark_v0.8.py`
- Збирання в `.exe` (PyInstaller) та установник Windows (Inno Setup): ярлики, автозапуск під час запуску Windows, видалення через «Програми та компоненти».
- Параметр `--minimized` — запуск у згорнутому вікні (для автозапуску).
- У встановленій програмі історія запусків зберігається в `%APPDATA%\PC Benchmark`.
- Іконка програми (`assets/pcbench.ico`).

## 0.7 — `benchmark_v0.7.py`
- macOS: визначення відеокарти MacBook через `system_profiler` (Apple M1/M2/M3… з кількістю GPU-ядер, Intel/AMD у старіших моделях). Назва показується в заголовку, у виборі GPU, у звіті та в порівнянні.
- У порівнянні для ПК з двома відеокартами показується дискретна.
- macOS: тест GPU пропускається з поясненням (замість помилки), виправлено прокрутку коліщатком у вкладці «Порівняння» та підпис системного диска.

## 0.6 — `benchmark_v0.6.py`
- Еталонні системи в порівнянні мають реальні моделі накопичувачів (Samsung 990 PRO, WD Black SN850X, Kingston A400 тощо) замість загальних описів.

## 0.5 — `benchmark_v0.5.py`
- Вибір відеокарти для тесту за справжніми назвами адаптерів (дискретна / вбудована).
- Попередження в журналі, якщо драйвер підставив іншу відеокарту.
- Вибір накопичувача зі списку томів: літера, тип, модель, вільне місце; кнопка «…» для довільної теки.
- Перевірка вільного місця; тест диска пропускається з поясненням, якщо диск недоступний.

## 0.4 — `benchmark_v0.4.py`
- У вкладці «Порівняння» заголовок рядка — компонент, що порівнюється (відеокарта, процесор, ОЗП, диск), нижче — решта конфігурації.
- Автоматичне визначення типу ПК, типу/частоти/модулів ОЗП, моделей накопичувачів і диска, на якому йшов тест.
- Повний склад комплектуючих для еталонних систем.

## 0.3 — `benchmark_v0.3.py`
- Тестування відеокарти через OpenGL: FP32-обчислення, фрактал, заповнення, текстурні вибірки, перевірка ідентичності кадрів.
- Вибір дискретної / вбудованої відеокарти (NVIDIA Optimus).
- Нова категорія балів «Відеокарта»; ваги загального бала: CPU 25% + 25%, GPU 20%, пам'ять 15%, диск 15%.

## 0.2 — `benchmark_v0.2.py`
- Новий темний інтерфейс: круговий індикатор загального бала, картки категорій, графік стрес-тесту із заливкою.
- Вкладка «Порівняння» з базою еталонних систем, історією власних запусків та імпортом JSON-звітів з інших ПК.

## 0.1 — `benchmark_v0.1.py`
- Перша версія: тести CPU (1 ядро / усі ядра), оперативної пам'яті, накопичувача, стрес-тест із перевіркою правильності обчислень і виявленням тротлінгу.
- Стандартний інтерфейс tkinter, консольний режим, збереження звіту в TXT/JSON.
